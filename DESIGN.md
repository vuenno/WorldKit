# WorldKit — Design System

The visual rules for WorldKit. Every token below lives in code in
`internal/ui/theme.go`; never hard-code a color, size or duration in a layout.

## Principles

- **Small and calm.** Compact controls, small type, plenty of dark space.
- **One accent.** Orange marks what is active or actionable — nothing else.
- **Motion with purpose.** Animations are short and eased; they explain a change, never decorate.

## Logo

The WorldKit logo (`assets/logo.png`) is the app's only brand
mark. Use it everywhere the app identifies itself; never redraw, recolor or crop it.

| Where                     | Size    | Notes                                                    |
|---------------------------|---------|----------------------------------------------------------|
| Exe, title bar, taskbar   | 16–256 px | Windows icon resource generated by `go-winres`         |
| Sidebar header            | 28 dp   | Right of the toggle, followed by "WorldKit" (14 sp SemiBold). Fades and clips with the labels when collapsed |

- Always draw it through the `Logo` widget (`internal/ui/logo.go`), which resamples to the exact
  pixel size so it stays sharp at every DPI.
- Keep it on dark surfaces (`colorAppBackground` / `colorSurface`); it has a transparent background.
- Its orange matches `colorPrimary`; don't place it directly next to large orange fills.

## Color tokens

| Token              | Hex       | Code name               | Use                                       |
|--------------------|-----------|-------------------------|-------------------------------------------|
| App background     | `#0D0D0F` | `colorAppBackground`    | Window / main content area                |
| Sidebar / Surface  | `#18181B` | `colorSurface`          | Sidebar, panels, cards                    |
| Elevated surface   | `#27272A` | `colorElevatedSurface`  | Hovered items, popovers, inputs           |
| Primary orange     | `#FF6B00` | `colorPrimary`          | Active nav item, primary buttons, focus   |
| Orange hover       | `#FF8A33` | `colorPrimaryHover`     | Hover state of orange elements            |
| Primary text       | `#F5F5F5` | `colorTextPrimary`      | Headings, active labels, body text        |
| Secondary text     | `#A1A1AA` | `colorTextSecondary`    | Inactive labels, hints, icons at rest     |
| Borders            | `#3F3F46` | `colorBorder`           | Dividers, outlines (1 dp)                 |
| Error text         | `#F87171` | `colorError`            | Error captions under a control only       |
| Scrim              | app background @ 80% | `colorScrim` | Dims the window behind a dialog         |

Selected text in inputs is `colorPrimary` at 40% opacity (`selectionOpacity`). Selected chat
lines in the log viewer use a lighter 18% (`lineSelectionOpacity`) so the chat colors stay readable.

### Chat colors

Saved chat lines use the colors GTA World's in-game chat uses, so logs look as they did in
game. Values come from the GTA World Chatlog Magician (a community tool that recreates the
in-game chat). They are the one exception to the single-accent rule; use them only for chat text.

| Line kind              | Hex       | Code name          |
|------------------------|-----------|--------------------|
| Says, shouts, server   | `#F1F1F1` | `colorChatSay`     |
| Says [low]             | `#C6C4C4` | `colorChatLow`     |
| Whispers               | `#EDA841` | `colorChatWhisper` |
| /me, /do               | `#C2A3DA` | `colorChatEmote`   |
| /b (OOC)               | `#B8BEC7` | `colorChatOOC`     |
| PMs                    | `#FBF724` | `colorChatPM`      |
| Session start header   | `#939799` | `colorChatHeader`  |

Rules:
- Text on orange uses `colorTextPrimary`.
- Don't put orange text on `colorElevatedSurface` at body size; use it for icons, bars and fills.

## Typography

Small by default. Sizes in `sp`.

| Role        | Size | Weight   | Color              |
|-------------|------|----------|--------------------|
| Brand name  | 14   | SemiBold | `colorTextPrimary` |
| Page title  | 16   | SemiBold | `colorTextPrimary` |
| Body        | 13   | Regular  | `colorTextPrimary` |
| Nav label   | 13   | Medium   | secondary / primary when active |
| Caption     | 11   | Regular  | `colorTextSecondary` |
| Chat line   | 12   | Regular  | chat color of its kind (log viewer) |

## Spacing & sizes

Spacing follows a 4 dp grid.

| Token            | Value  | Use                                   |
|------------------|--------|---------------------------------------|
| `spacingTiny`    | 4 dp   | Icon ↔ tight elements                 |
| `spacingSmall`   | 8 dp   | Gap between nav items, sidebar padding|
| `spacingMedium`  | 12 dp  | Icon ↔ label, nav item padding        |
| `spacingLarge`   | 24 dp  | Page padding                          |
| `iconSize`       | 18 dp  | All icons                             |
| `navItemHeight`  | 36 dp  | Nav items and the toggle button       |
| `cornerRadius`   | 6 dp   | Nav items, buttons, cards, inputs     |
| `buttonHeight`   | 32 dp  | Buttons                               |
| `inputPaddingY`  | 8 dp   | Vertical padding inside text fields   |
| `dialogWidth`    | 420 dp | Max dialog width                      |
| `contentMaxWidth`| 640 dp | Max width of page content (Settings, Logs list) |
| `characterOptionsMaxHeight` | 132 dp | Max height of the log filter's character options |

## Sidebar (navbar)

Placement: fixed on the **left**, full window height, `colorSurface` background,
separated from content by a 1 dp `colorBorder` line on its right edge.

### States

| State     | Width  | Shows                 |
|-----------|--------|-----------------------|
| Expanded  | 200 dp | Icon + label          |
| Collapsed | 58 dp  | Icon only, centered (2 × (8 + 12) + 18) |

### Toggle button

- The **very first element** at the top of the sidebar (left of the logo), a square the width of
  the collapsed sidebar's content, so it never moves while animating.
- A menu icon (`☰`) in `colorTextSecondary`; hover → `colorElevatedSurface` background, icon `colorTextPrimary`.
- Click switches between expanded and collapsed. Clicking mid-animation reverses smoothly from the current width.
- Below it, a 1 dp `colorBorder` divider separates it from the navigation items.

### Navigation items

- Stacked **vertically**, top-aligned, with an **8 dp gap** (`spacingSmall`) between items.
- Each item: `navItemHeight` tall, `cornerRadius` corners, `spacingMedium` horizontal padding,
  icon (`iconSize`) then label (13 sp) separated by `spacingMedium`.
- States:
  - **Rest:** transparent background, icon + label `colorTextSecondary`.
  - **Hover:** `colorElevatedSurface` background, icon + label `colorTextPrimary`.
  - **Active:** `colorElevatedSurface` background, icon `colorPrimary`, label `colorTextPrimary`,
    plus a 3 dp `colorPrimary` indicator bar on the item's left edge.
- Collapsed: labels are hidden (faded out and clipped); icons stay at the same position so they
  don't jump during the animation.

### Animation

| Property   | Value                                  |
|------------|----------------------------------------|
| Duration   | **200 ms**                             |
| Easing     | Ease-in-out cubic                      |
| Animates   | Sidebar width; label opacity (0 ↔ 1)   |

- Width interpolates between collapsed and expanded widths each frame; content area resizes with it.
- Label opacity follows the same eased progress, so labels fade as the bar narrows.
- Driven by `gtx.Now` and `op.InvalidateCmd` — only redraw while animating, never on idle.

## Buttons

- Height 32 dp, `cornerRadius` corners, label 13 sp, horizontal padding 12 dp.
- **Primary:** `colorPrimary` fill → `colorPrimaryHover` on hover, `colorTextPrimary` text.
- **Secondary:** `colorElevatedSurface` fill, 1 dp `colorBorder`, `colorTextPrimary` text.
- Labels are 13 sp Medium, one line. Code: `primaryButton` / `secondaryButton` in `internal/ui/button.go`.
- Place a primary button first (left), then secondary, `spacingSmall` apart.
- **Toggle** (on/off filter, `toggleButton`): looks primary while on (orange marks what is
  active) and secondary while off. Toggles sit `spacingSmall` apart and wrap onto new rows
  (also `spacingSmall` apart) when they don't fit (`layoutWrapped` in `internal/ui/wrap.go`).

## Cards

- `colorSurface` fill, 1 dp `colorBorder`, `cornerRadius` corners, `spacingLarge` padding, full width.
- Section title inside a card: 13 sp SemiBold; description under it as a caption.
- Cards on a page are `spacingMedium` apart. Code: `card` in `internal/ui/dialog.go`.
- **Panel:** a compact card with `spacingMedium` padding, for tool panels inside a page (e.g. the
  log filters). Code: `panel` in `internal/ui/dialog.go`.
- Cards, panels, text fields and list rows share one background: `outlinedSurface` (fill + 1 dp
  `colorBorder`, `cornerRadius`).

## List rows

- Clickable rows in a vertical list (e.g. saved sessions), `spacingSmall` apart, full width up to
  `contentMaxWidth`.
- `colorSurface` fill → `colorElevatedSurface` on hover, 1 dp `colorBorder`, `cornerRadius`,
  `spacingMedium` padding, pointer cursor.
- Left: title (13 sp SemiBold) with a caption under it (`spacingTiny` gap). Right: a caption,
  vertically centered (e.g. "Session #12"). Code: `sessionRow` in `internal/ui/logs_page.go`.

## Log viewer

- Fills the page (no max width), `spacingLarge` padding.
- Header row: secondary **Back**, then the page title with a caption under it, then on the
  right a **Filters** toggle and primary **Copy** (`spacingSmall` apart); `spacingMedium` gaps.
  Filters reads "Filters (N)" and turns orange while N options are on; clicking it opens or
  closes the filter panel.
- Filter panel (`spacingMedium` below the header, only while open): a `panel` with
  - **Actions**: section title, a secondary **Clear** on the right while any option is on (its
    height is always reserved so nothing jumps), then toggles `/me`, `/do`, `/b (OOC)`, `IC`.
  - **Characters** (`spacingMedium` below): section title + "N detected" caption, then one
    toggle per character, "Name · line count", most active first. At most
    `characterOptionsMaxHeight` (132 dp, about 3½ rows) tall; scrolls beyond that.
  - **Display** (`spacingMedium` below): a **Timestamps** toggle, on by default. Off strips the
    leading `[HH:MM:SS]` from shown and copied lines. Display options don't count toward
    "Filters (N)" and Clear leaves them alone.
- A caption with the line count ("Showing 3 of 8 lines."), `spacingMedium` above and
  `spacingSmall` below.
- The text panel fills the remaining height: `outlinedSurface` in `colorSurface`,
  `spacingMedium` padding, a scrollable list of lines (scrollbar `colorBorder`, hover
  `colorTextSecondary`). Each line is 12 sp (`textSizeChatLine`) in its chat color (below),
  with a text cursor. Whole lines are selected by dragging (Shift+click extends, Ctrl+A all);
  a selected line gets a full-width `lineSelectionOpacity` accent tint. An empty result shows a
  caption instead.
- Copy (button or Ctrl+C) copies the selected lines, or every visible line when none are selected;
  the line-count caption adds "N selected." and "Copied to the clipboard."
- Dates are shown as `Mon 02 Jan 2006, 15:04 UTC`.

## Text fields

- `colorElevatedSurface` fill, 1 dp `colorBorder`, `cornerRadius` corners,
  `spacingSmall` horizontal / `inputPaddingY` vertical padding, 13 sp text, hint in `colorTextSecondary`.
- An action button for the field sits to its right, `spacingSmall` apart.
- Errors appear below as a caption in `colorError`, `spacingSmall` above it.

## Switches

- Material switch: thumb `colorPrimary` when on, `colorTextSecondary` when off, track `colorBorder`.
- Right-aligned in its row, with the section title on the left.

## Dialogs

- Modal: `colorScrim` covers the whole window and swallows clicks.
- A card, centered, at most `dialogWidth` wide: page title (16 sp SemiBold), `spacingSmall`,
  body text, `spacingLarge`, then the controls. Only one dialog shows at a time.
