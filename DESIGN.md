# WorldKit — Design System

The visual rules for WorldKit. Every token below lives in code in
`internal/ui/theme.go`; never hard-code a color, size or duration in a layout.
The reference mockups are the **WorldKit Redesign** design canvas (one artboard per screen
plus a type/color/component sheet); keep the app and the canvas telling the same story.

## Principles

- **Calm and dark.** A near-black ground, quiet surfaces, generous spacing; chat colors are
  the brightest thing on screen.
- **One accent.** Orange marks the one main action on a screen and what is active — nothing
  else. Green only ever means "capturing / live", always next to a label.
- **Show what matters.** Filters, status and actions are visible where they are used, not
  hidden behind menus: the capture status lives in the sidebar, filters sit above the log,
  actions on a selection float next to it.
- **Motion with purpose.** Animations are short and eased; they explain a change, never decorate.

## Window chrome

WorldKit has **no Windows title bar**: the window is created undecorated
(`app.Decorated(false)`) and draws its own.

- **Title bar** (`titleBar`, `internal/ui/title_bar.go`): a `titleBarHeight` (40 dp) strip
  above the page, app-background color, no title text. Its empty part is the window's
  move area: drag to move, double-click to maximize, Windows snapping works.
- **Caption buttons** at its right: minimize, maximize/restore, close. Each
  `windowButtonWidth` (46 dp, as in Windows) wide, full bar height, 10 dp glyphs drawn with
  1 dp lines in `colorTextSecondary`. Hover: `colorElevatedSurface` fill and
  `colorTextPrimary` glyph; close hovers `colorCloseHover` (Windows red).
- The sidebar's brand area is a move area too. **Never put a button inside a move area**:
  Windows takes those clicks before the app sees them.
- Resizing works at every window edge (Windows handles it).

## Logo

The WorldKit logo (`assets/logo.png`) is the app's only brand mark. Use it everywhere the
app identifies itself; never redraw, recolor or crop it.

| Where                     | Size      | Notes                                                   |
|---------------------------|-----------|---------------------------------------------------------|
| Exe, taskbar              | 16–256 px | Windows icon resource generated by `go-winres`          |
| Sidebar header            | 32 dp     | Followed by "WorldKit" (15 sp Bold) over "for GTA World" (11 sp, tertiary). Fades and clips with the labels when collapsed |

- Always draw it through the `Logo` widget (`internal/ui/logo.go`), which resamples to the
  exact pixel size so it stays sharp at every DPI.
- Keep it on dark surfaces; it has a transparent background.

## Typography

Two embedded typefaces (`assets/fonts`, OFL-1.1), loaded by `newShaper` in
`internal/ui/fonts.go`; system fonts are never used, so text looks the same on every PC.

- **Geist** (`fontUI`): every label, title, button and chat line. Weights 400/500/600/700.
- **Geist Mono** (`fontMono`): times, counts, sizes and paths — anything people compare
  digit by digit. Weights 400/500.
- **Arial Bold** (and Bold Italic) only in extracted screenshot images (see Chat screenshots).

| Role          | Token                 | Size | Weight   | Color                 |
|---------------|-----------------------|------|----------|-----------------------|
| Page title    | `textSizePageTitle`   | 28   | SemiBold | `colorTextPrimary`    |
| Screen title  | `textSizeScreenTitle` | 20   | SemiBold | `colorTextPrimary` (an opened log or screenshot; dialog titles) |
| Section       | `textSizeSection`     | 15   | SemiBold | `colorTextPrimary` (card titles, brand name) |

## Icons

Line icons on a 24-unit grid with 1.8-unit rounded strokes (`strokeIcon`,
`internal/ui/icons.go`), written in a tiny SVG-path subset (M L H V Q Z, plus `O` circle and
`R` rounded rect). Add new icons there; never use filled Material icons.

## Components

- **Buttons** (`button.go`): `primaryButton` (orange fill, `colorOnPrimary` SemiBold label;
  one per screen), `secondaryButton` (`colorSurface` + 1 dp `colorBorder`, Medium label),
  `ghostButton` (no fill until hovered; inside floating menus), `dangerButton` (filled
  `colorDanger`, confirming a delete), `iconButton` (square). Modifiers: `withIcon` (icon
  before the label, 8 dp gap), `withHeight`, `withKind`, `asDanger` (label/icon in
  `colorDanger`). Horizontal padding 14 dp.
- **Text field** (`textField`): `colorAppBackground` fill, 1 dp `colorBorder`, `radiusControl`,
  optional leading icon in `colorTextTertiary`; `isMono` for paths.
- **Segmented control** (`segmentedControl`): pick one of a few; `colorSurface` box with
  3 dp padding, chosen segment `colorPressed` with `colorTextPrimary`, others secondary.
- **Number stepper** (`numberStepper`): a whole number in a range; the segmented control's box
  with ghost square **−** / **+** icon buttons (`segmentHeight`) around the value and its
  unit in 13 sp Geist Mono, `stepperValueWidth` wide. Clicks past either end do nothing.
- **Switch** (`toggleSwitch`): 40×24 track, `colorPrimary` with a `colorOnPrimary` knob when on,
  `colorPressed` with a secondary knob when off.
- **Status pill** (`statusPill`): dot + 12 sp SemiBold label in the status color on its tint.
- **Chip** (`removableChip`): `colorElevatedSurface`, 24 dp, label + × to remove.
- **Count badge** (`countBadge`): orange pill with a dark count, next to a control's label.
- **Link** (`linkButton`): 12 sp SemiBold `colorLink` text action.
- **Cards** (`card`, `outlinedSurface`): `colorSurface`, 1 dp `colorDivider`, `radiusCard`.
  **Settings cards** (`settingsCard`): title row, then rows separated by dividers.
- **Floating surface** (`floatingSurface`): `colorElevatedSurface`, 1 dp `colorBorderStrong`,
  `radiusFloating` and a soft shadow; menus and toasts.
- **Toast** (`toast`): floating, bottom-right of its area, check icon in `colorLive` (or ×
  in `colorDanger`), 13 sp message, optional link; hides after `toastDuration` (4 s).
- **Dialog** (`dialog`): `colorScrim` over the window, centered card ≤ `dialogWidth` (or
  its `width`): screen title, secondary body text, 24 dp, controls (primary/danger first).
- **Color swatch** (`layoutSwatch`): a 22 dp dot in its color; hovered, a 2 dp
  `colorTextPrimary` ring. Clicking applies the color; swatches have no selected state.
- **Number field** (`numberField`, `inputs.go`): one number edited in place, 32 dp, the input
  look with `radiusMenu`, a tertiary prefix ("X", "W") and unit ("px", "°", "%"), the value in
  13 sp Geist Mono; orange outline while focused. Enter or clicking away commits; anything
  that isn't a number snaps back.
- **Slider** (`slider`): a 4 dp `colorPressed` track, orange up to the 16 dp
  `colorTextPrimary` knob, `segmentHeight` tall. Click or drag anywhere on it.
- **Dropdown** (`dropdownMenu`, `menu.go`): a 36 dp secondary-style button with a chevron
  (Geist Mono label for sizes) opening a floating menu (260 dp wide, up to 360 dp tall) below
  it: 32 dp rows (label, Geist Mono detail at the right), group labels as headings; closes on
  a pick or any click outside.
- **Checkbox** (`checkbox`): a 16 dp box, 4 dp radius, marking menu rows that toggle (Characters).
  Off: 1 dp `colorBorderStrong` outline (`colorTextTertiary` while the row is hovered). On:
  `colorPrimary` fill with a 12 dp `colorOnPrimary` check. Always drawn, so the labels after it
  stay in one column; 10 dp before the label.
- **Disabled controls** (`layoutEnabled`): drawn at `disabledOpacity` (0.4), no input.
- **Confirm prompt** (`confirmPrompt`): a `dialog` with a danger confirm button and Cancel.
- **Picture editor** (`pictureEditor`): text edited on a rendered image. Text cursor over
  the whole preview; selection `colorPrimary` at `selectionOpacity` behind the glyphs;
  caret `caretWidth` (1 dp) `colorTextPrimary`, shown while focused, not blinking.

## Sidebar

Fixed on the left, full height, `colorSidebar`, 1 dp `colorDivider` on its right edge,
12 dp padding. Expanded 232 dp; collapsed `2 × (12 + 12) + 18 = 66 dp` (icons stay put).

- **Header**: logo + name/subtitle (a window move area), collapse button (ghost icon button,
  panel icon) at the right. Collapsed, only the collapse button shows.
- **Main destinations**, 4 dp apart, in two groups split by a 1 dp `colorDivider` line
  (12 dp side insets; a destination with `StartsGroup`): making chat images — **Logs** (file
  icon), **Log Screenshots** (image icon) — then using them — **Screenshot Editor** (layers
  icon), **Saved Screenshots** (images icon).
- **Badge**: a `navBadgeSize` (6 dp) orange dot on a nav icon's top-right corner means work
  in progress on that page (the editor has layers). Visible collapsed too.
- **Capture card** at the bottom: status dot + title ("Capturing", "Watching", "Retrying…",
  "Not capturing") and a caption ("Last line saved at 18:45:12"). `colorSurface`, 1 dp
  divider, 12 dp padding. Collapsed: the dot alone.
- **Settings** (sliders icon) below the card.
- Nav item: 40 dp, `radiusControl`, 12 dp side padding, icon 18 dp then label 14 sp Medium,
  12 dp apart. Rest: secondary label, tertiary icon. Hover: `colorElevatedSurface`,
  primary label and icon. Active: `colorElevatedSurface`, primary label, orange icon, and a
  3×20 dp orange bar at the left edge.
- Animation: 200 ms ease-in-out cubic on width and label opacity; frames only while animating.

## Extract image dialog

Opened by **Extract image** (`extractDialog`, `internal/ui/extract_dialog.go`); a `dialog`
up to `extractDialogWidth` (720 dp) over the log viewer.

- Title "Extract image"; message "Save 4 lines as they are, or edit them first?" (while
  editing: "Select text on the image, then pick Italic or a color. Click and type to change
  the text."; with every line emptied: "Every line is empty. Click the image and type to
  save something.").
- While editing, first: a row of secondary **Italic** (italic icon, 32 dp), a vertical
  divider, the color swatches 4 dp apart and ghost **Default** (back to the automatic
  colors), then a caption (Ctrl+A, nothing selected = all text, Ctrl+Z), 12 dp above the
  preview.
- **Preview**: rounded `radiusCard` checkerboard, at least `screenshotPreviewHeight`
  (140 dp) tall, 16 dp padding, the rendered PNG centered at 1:1 (scaled down to fit when
  wider); redrawn in the background on every change. "Drawing…" before the first preview.
  While editing it is a **picture editor**: drag, Shift+click or Ctrl+A select text on the
  image; click places the caret; typing, Backspace, Delete, Enter (new line), arrows,
  Home/End (Shift extends) and Ctrl+Z work as in a text field.
- 12 dp below: "Background" + segmented **Transparent · Dark · Light** + caption "Dark and
  Light put a box behind each line." (one line).
- 8 dp below: "Font size" + number stepper **− 14 px +** (10–24 px) + caption "A bigger
  font makes a bigger image." Option labels sit in an `optionLabelWidth` column so the
  controls line up.
- 8 dp below: "Max width" + number stepper **− 914 px +** (200–1800 px, steps of 50 landing
  on round values) + caption "Longer lines wrap to fit. Use Edit to break lines yourself."
  (while editing: "… Press Enter for a break of your own."). It follows the font size (the
  in-game width) until the user picks a width. All three choices stay for the next extract.
- **Presets** (once any is saved): a "Preset" row above Background with a dropdown of the
  saved looks (name, font size; "Custom" once a choice changes) and caption "A saved
  background, font size and width." The first Extract in a log starts with the default
  preset from Settings. 12 dp below Max width: **Save as preset…** (`presetNaming`, as in
  the export dialog) saves background, font size and max width; a width still following
  the font size is saved as "in-game width".
- The body scrolls; the buttons stay in view 24 dp below it: primary **Save image** (image
  icon), secondary **Edit** (pencil icon; hidden once editing), secondary **Cancel**.
- Italic, colors and Default act on the selection, or on all the text with nothing
  selected. Italic makes the selection italic, or upright when all of it already is.

## Chat screenshots (extracted images)

What Extract image writes: a PNG players lay over game screenshots, styled like the in-game chat.

- Font: **Arial Bold**, read from `%WINDIR%\Fonts\arialbd.ttf`; italic text uses
  **Arial Bold Italic** (`arialbi.ttf`). Bundled Go Bold / Go Bold Italic if those fail.
- Size: picked per extract, **10–24 px**, default **14 px** (the in-game chat). At 14 px:
  18 px line height and a 900 px wrap; both scale with the font (line height rounded), so
  lines wrap at the same words and the image grows with the text. **Max width** (200–1800 px,
  default that in-game width plus the 7 px margins) caps the image: lines wrap at spaces to
  fit, and a word longer than the limit breaks between characters, so the image is never
  wider. Lines broken by hand (Enter while editing) always start a new row. Fixed at every size:
  6 px padding, each line in its chat color with a 1 px black outline (drawn at the 8
  neighboring offsets) so it reads over any picture. Wrapped lines keep their colors. The
  image is just big enough for the text. Pixel values (not dp/sp) because they describe
  the file, not the UI; they live in `internal/screenshot/render.go`. The PNG records its
  font size (tEXt chunk `WorldKit:FontSize`).
- **Markup** in a chat line: `/text/` → italic, slashes removed; `*text*` → the /me color
  (`colorChatEmote`), asterisks removed. Markers count only at word edges (`and/or`,
  `2 * 3` and a /me line's leading `* ` stay as typed).
- **Backdrop**: Transparent draws nothing behind the text. Dark/Light draw one box per
  drawn row: the row's height (18 px at 14 px), from 5 px left of its text to 5 px right
  of it, rows flush (a stepped shape for uneven lines), everything else transparent.
